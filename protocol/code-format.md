# Capability code format v1

## Secret

A v1 capability contains exactly 20 bytes generated by the operating-system
CSPRNG. The checksum is the first 10 bits of:

```text
SHA-256("envshare/code-checksum/v1" || secret)
```

The checksum detects transcription errors and is not key stretching or added
entropy.

## Text representation

The canonical representation is:

```text
esh1-<32 Crockford Base32 secret symbols>-<2 checksum symbols>
```

The 34 data symbols are grouped from left to right in groups of four, with a
short final group when necessary. The ASCII prefix is lowercase `esh1`; encoded
symbols are uppercase. The exact grouping emitted by the reference implementation
is normative for display but separators are ignored while parsing.

The alphabet is `0123456789ABCDEFGHJKMNPQRSTVWXYZ`. Parsing is ASCII-only,
case-insensitive, ignores `-`, maps `O` to `0` and maps `I` and `L` to `1`, and
rejects every other character. It verifies prefix, exact length, unused trailing
bits and checksum before network activity. Invalid input produces one generic
error and is never echoed.
