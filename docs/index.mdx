Envshare makes a short-lived, encrypted handoff between two online computers.
The sender stays in control until one receiver claims the file.

```bash
envshare send .env
```

<Warning>
Envshare 0.x has not completed an independent security review. Use test
credentials for now.
</Warning>

## The normal flow

<Steps>
  <Step title="Send the file">
    Run `envshare send .env` and keep the terminal open.
  </Step>
  <Step title="Pass the share code">
    Send the code through a private channel you already trust.
  </Step>
  <Step title="Receive the file">
    Run `envshare receive`, enter the code, and choose where to save it.
  </Step>
</Steps>

The built-in public network works without accounts or extra network flags. The
public node helps the peers find and relay each other, but it should never see
the share code or plaintext payload.
